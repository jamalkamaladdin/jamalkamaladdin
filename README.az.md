İşimin böyük hissəsi bizneslə sistemin ortasında keçir: əslində nə istənildiyini
müəyyən etmək, sonra mövcud məhdudiyyətlərin qəbul edəcəyi həlli tapmaq.

Maraqlı sual adətən «bunu necə yazaq?» deyil. Sual «bunu niyə belə qururuq?»
olur, və həmin seçimin bir ildən sonra nəyə başa gələcəyidir.

## Azərbaycan dili, upstream layihələrdə

Developer alətlərinin çoxunda Azərbaycan dili yoxdur. Çətin olduğu üçün yox,
sadəcə heç kim faylı göndərmədiyi üçün. Tərcümə faylı koddur: testi, sıralama
qaydası, cəm formaları və placeholder müqaviləsi var, üstəlik onu yazan adam
getdikdən çox sonra da repozitoriyada qalır.

Aşağıdakı işlərin hamısı əl ilə yazılıb, mənbə dili ilə açar və placeholder
paritetinə görə ölçülüb, layihə maintainer-ləri tərəfindən nəzərdən keçirilib.
İndiyə qədər doqquz layihəyə on altı pull request merge olunub.
